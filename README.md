# Forge · 本地代码智能体

跑在浏览器里的 code agent 工作台：与 agent 对话，它直接阅读 / 搜索 / 修改你本地项目里的文件，也能执行终端命令 —— 每一步敏感操作都由你授权。模型 API 由你自己接入，Key 只保存在本机。

## 使用

1. **配置模型接口**（右上角「设置」）：支持两种协议，可保存多套随时切换
   - **OpenAI 兼容**：OpenAI / DeepSeek / Kimi / 各类中转站，填 Base URL + API Key + 模型名
   - **Anthropic**：Claude 官方协议
   - 「测试连接」可即时验证配置；Key 加密脱敏展示，不会回传明文
2. **新建会话**：选一个工作目录 + 权限模式。agent 的一切文件操作都被限定在该目录内（含 symlink 穿越防护）
3. **对话**：agent 会浏览目录、读文件、搜索、改代码、跑命令；每一步工具调用和代码差异（diff）都实时可见

## 权限模式（会话中随时可切）

| 模式 | 行为 |
| --- | --- |
| 只读 | 只能浏览与读取，不能改文件、不能跑命令 |
| 确认（默认） | 读操作自动；写文件 / 删文件 / 执行命令前弹出授权卡，附 diff 预览，可选「允许一次 / 本会话内都允许 / 拒绝」 |
| 命令自动审批 | 终端命令直接执行不弹确认；写文件 / 删文件仍逐次确认 |
| 完全访问 | 所有操作直接执行，不再弹任何确认（危险档，界面上有红色警示） |

## Agent 能力

`list_dir` / `read_file` / `search_text` / `find_files` / `write_file` / `edit_file`（精确替换，支持 edits 数组一次提交多处改动、replace_all）/ `delete_path` / `run_command`（bash，cwd 限定，输出实时流式回传）/ `update_plan`（多步任务的进度清单，界面实时显示进度条）

互不依赖的只读调用并行执行；长对话自动压缩较早的工具输出；中断时自动补全工具结果保证对话不损坏。

## 编程体感

- **@ 文件引用**：输入框打 `@` 补全项目文件，方向键选择插入
- **实时命令输出**：终端卡片里 stdout/stderr 边跑边滚
- **任务进度条**：agent 边做边勾清单，当前进行到哪一项一目了然
- **diff 语法着色**：授权卡与结果卡里的代码差异按语言高亮
- **点路径开预览**：工具卡上的文件名点一下，右侧文件树自动展开并打开
- **一键复制**：回复里的代码块悬停出现复制按钮
- **自动命名**：会话标题取你的第一句话；每轮结束显示用时与工具调用数

## 架构

- `server.mjs` + `server/`：Node 内置模块实现的单进程服务（8000 端口）——`/api/*` 是自研 agent 后端，其余走 Vite（前端 + HMR）
  - `agent.mjs` agent 主循环 + OpenAI / Anthropic 双协议流式适配（tool calling 聚合）
  - `tools.mjs` 工具实现与目录安全边界
  - `api.mjs` REST + SSE 路由；`store.mjs` 会话持久化（`agent-data/`）
- `src/`：React 19 + Tailwind 工作台（会话列表 / 对话流 / 授权卡 / diff 视图 / 文件树与代码预览 / 深浅双主题）
